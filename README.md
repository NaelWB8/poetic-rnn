# Poetic Text Generation with Recurrent Neural Networks

This repository contains a simple character-level text generator built using an LSTM-based Recurrent Neural Network in TensorFlow. The model is trained on a subset of Shakespeare’s text and generates new text based on learned patterns.

## Features
- Character-level text generation  
- Temperature-based sampling for creativity control  
- Automatic download of dataset  
- One-file training and generation workflow  
- Saved model (`.keras`) is reused to avoid retraining

## Requirements
Install dependencies with:

```bash
pip install tensorflow numpy
```

TensorFlow will automatically download the Shakespeare dataset on first run.

## How It Works

### 1. Dataset
The script downloads *shakespeare.txt* from TensorFlow’s public dataset repository.  
A slice of the text (characters 300k to 800k) is used to reduce training size and speed up learning.

### 2. Preprocessing
- All unique characters in the text are extracted.
- A mapping between characters and indices is created.
- Training samples are generated by sliding a 40-character window across the text with a step of 3.
- Inputs and labels are one-hot encoded into NumPy arrays.

### 3. Model Architecture
The model is a simple sequential network:

```text
LSTM (128 units)
Dense (len(characters))
Softmax activation
```

It is optimized using RMSprop and categorical crossentropy.

### 4. Training
If the file `textgenerator_model.keras` does not exist, the script:
1. Builds the model  
2. Prepares training data  
3. Trains for 1 epoch  
4. Saves the model  

On subsequent runs, the saved model is loaded automatically.

### 5. Text Generation
Text is generated one character at a time:
- A random starting sequence is selected from the text.
- The model predicts the next character using temperature-scaled probabilities.
- The sequence updates and continues until the desired length is reached.

### Temperature
The temperature parameter controls randomness:

| Temperature | Behavior |
|------------|----------|
| 0.2 | Highly predictable, stable |
| 0.4 | Balanced, more natural |
| 0.6 | Creative, varied |
| 0.8 | Chaotic, experimental |

### Running the Script
Run:

```bash
python main.py
```

The script will:
- Train a new model if none exists  
- Generate text at temperatures 0.2, 0.4, 0.6, and 0.8  
- Print each sample to the console  

### Output Example
```
---------0.2----------
<generated text>

---------0.4----------
<generated text>

...
```

## Notes
- This project is designed for simplicity and demonstration.
- Running more epochs will improve the model’s output quality.
- You can train the model on your own dataset by replacing the input text.
