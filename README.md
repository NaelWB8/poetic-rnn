# Poetic RNN

This project explores how a character-level Recurrent Neural Network can learn writing patterns from classical literature and generate new poetic text. The model is trained on a Shakespeare corpus, but you can replace it with any text dataset you prefer.

## Overview

The goal of this project is to build a simple yet functional RNN-based text generator. The model learns how characters follow one another in a body of text, then produces new text sequences based on a starting prompt. This is an introductory exercise in neural text generation using Python.

## Features

- Character-level text generation  
- Simple RNN architecture  
- Training script for custom datasets  
- Text generation from a prompt  
- Flexible project structure for experimentation
